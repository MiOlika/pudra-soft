# Сайт Pudra Soft

Сайт [pudra-soft.ru](https://pudra-soft.ru) с бесплатными приложениями для Windows: DoSka, Time Filler и Clip Ink.

Сайт сделан на обычном HTML, CSS и JavaScript без фреймворков. Страницы собираются скриптом на Python из словарей
с текстами, а готовый сайт лежит в папке `docs/`, откуда его публикует GitHub Pages.

## Где что лежит

```
site/                    исходники сайта, правки делаются здесь
├── build.py             сборка: создаёт страницы в docs/
├── l10n/
│   ├── app_ru.arb       все тексты на русском
│   └── app_en.arb       все тексты на английском
├── src/
│   ├── style.css        оформление, цвета светлой и тёмной темы
│   ├── site.js          темы, вкладки, галерея, версии с GitHub
│   ├── favicon.png
│   ├── zen_….html       подтверждение прав для Яндекс Дзена
│   └── images/
│       ├── dark/        картинки для тёмной темы
│       └── light/       картинки для светлой темы
└── icons/               значки (SVG), встраиваются в страницы

docs/                    готовый сайт, создаётся сборкой, вручную не править
└── CNAME                домен pudra-soft.ru, сборка его не трогает
```

Страницы сайта:

| Адрес | Страница |
|---|---|
| `/` и `/en/` | Главная на русском и английском |
| `/doska/`, `/time-filler/`, `/clip-ink/` | Страницы приложений на русском |
| `/en/doska/`, `/en/time-filler/`, `/en/clip-ink/` | Страницы приложений на английском |
| `/sitemap.xml`, `/robots.txt` | Карта сайта и правила для поисковиков, создаются сборкой |

## Что нужно установить

Только [Python 3.8 или новее](https://www.python.org/downloads/). Дополнительные пакеты не нужны. При установке на
Windows отметьте пункт «Add Python to PATH».

Проверить, что Python установлен:

```powershell
python --version
```

## Сборка

Из корня проекта:

```powershell
cd D:\Programming\Flutter\pudra_soft
python site\build.py
```

Скрипт полностью пересоздаёт папку `docs/`: удаляет всё, кроме `CNAME`, и собирает сайт заново. Поэтому файлы в
`docs/` руками не правят, их перезапишет следующая сборка.

Собрать в другую папку, не трогая `docs/`, например для пробы:

```powershell
python site\build.py C:\Temp\pudra_preview
```

## Просмотр на компьютере

Запустить сервер:

```powershell
python -m http.server 8000 --bind 0.0.0.0 -d docs
```

Открыть в браузере [http://localhost:8000](http://localhost:8000).

Остановить сервер: нажать **Ctrl + C** в окне PowerShell, где он запущен, или просто закрыть это окно.

После каждой пересборки обновляйте страницу клавишами **Ctrl + F5**, иначе браузер может показать старые стили из кэша.

Если порт 8000 занят, укажите другой, например `8080`, и откройте `http://localhost:8080`.

## Просмотр на телефоне

Телефон и компьютер должны быть в одной сети Wi-Fi.

1. Узнайте адрес компьютера командой `ipconfig`: строка **IPv4-адрес** у адаптера Wi-Fi, например `192.168.1.106`.
   Адреса виртуальных адаптеров (vEthernet, VirtualBox, VPN) не подходят.
2. Запустите сервер командой из раздела выше. Обязательно с `--bind 0.0.0.0`.
3. Откройте на телефоне `http://192.168.1.106:8000`, подставив свой адрес и порт.

Ссылка `http://0.0.0.0:8000`, которую пишет сервер при запуске, в браузере не открывается, это нормально.
Адрес `127.0.0.1` и `localhost` на телефоне тоже не подойдут: они означают сам телефон.

Если телефон не подключается, разрешите порт в брандмауэре. В PowerShell **от имени администратора**:

```powershell
New-NetFirewallRule -DisplayName "Pudra preview 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private,Public
```

Удалить это правило, когда оно больше не нужно:

```powershell
Remove-NetFirewallRule -DisplayName "Pudra preview 8000"
```

## Публикация

Сайт публикует GitHub Pages из папки `docs/` ветки `main`. Чтобы обновить сайт:

```powershell
python site\build.py
git add -A
git commit -m "Обновление сайта"
git push
```

Через одну-две минуты после `git push` изменения появятся на [pudra-soft.ru](https://pudra-soft.ru). Если не появились,
откройте репозиторий на GitHub → вкладка **Actions** и посмотрите, не упала ли публикация, а в **Settings → Pages**
проверьте, что источник — ветка `main`, папка `/docs`, а домен — `pudra-soft.ru`.

Перед публикацией стоит собрать сайт и посмотреть его локально.

## Частые правки

### Изменить текст

Тексты лежат в `site/l10n/app_ru.arb` и `site/l10n/app_en.arb`. Найдите нужную строку по тексту, исправьте её в обоих
файлах и пересоберите сайт. Ключи (слева от двоеточия) не меняйте.

Заголовки и описания страниц для поисковиков задаются в `site/build.py`: главная в `PAGE`, приложения в `APP_PAGES`.

### Выпустить новую версию приложения

Ничего делать не нужно. Сайт сам берёт последнюю версию и ссылку на установщик из релизов
`github.com/MiOlika/<приложение>/releases`. Версия в `APPS` в `site/build.py` запасная: она видна, только если GitHub
не ответил. Её можно обновлять время от времени.

Установщиком считаются файлы `.msi`, `.exe`, `.msix` и `.zip` в релизе. Черновики релизов на сайт не попадают.

### Заменить скриншоты или логотипы

Картинки лежат в `site/src/images/dark/` и `site/src/images/light/`. Если для светлой темы отдельной картинки нет,
положите в обе папки одинаковый файл.

Рекомендуемый формат — WebP: он в несколько раз легче PNG. Скриншоты удобно делать шириной до 1600 пикселей, логотипы
192 × 192. Новые скриншоты перечисляются в `APPS` в `site/build.py`, в поле `shots`.

### Добавить приложение

1. В `site/build.py` добавьте запись в `APPS` и в `APP_PAGES`.
2. В оба файла `.arb` добавьте тексты с ключами по образцу существующих: `<key>Subtitle`, `<key>Description`,
   `<key>Details`, `<key>Feature1…5`, `<key>Benefit1…5`, `<key>Faq1…4Question` и `<key>Faq1…4Answer`.
3. В `site/src/style.css` добавьте цвет приложения для обеих тем (`--accent-…`) и класс `.app-<slug>`.
4. Положите логотип и скриншоты в обе папки картинок и пересоберите сайт.

### Изменить цвета

Все цвета заданы переменными в начале `site/src/style.css`: первый блок — тёмная тема, блок
`:root[data-theme="light"]` — светлая.

### Добавить значок

Положите SVG с `viewBox="0 0 24 24"` в `site/icons/` и используйте его имя в `build.py` через `icon('имя')`. Значки
берутся из набора [Material Design Icons](https://pictogrammers.com/library/mdi/).

## Поисковики

- Карта сайта `sitemap.xml` и `robots.txt` создаются при каждой сборке.
- В [Яндекс Вебмастере](https://webmaster.yandex.ru) и [Google Search Console](https://search.google.com/search-console)
  отправьте адрес `https://pudra-soft.ru/sitemap.xml`.
- Файлы и мета-теги подтверждения прав кладутся в `site/src/` (файл) или в `render_head` в `site/build.py` (мета-тег),
  иначе сборка их удалит.
