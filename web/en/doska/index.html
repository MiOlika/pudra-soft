DoSka — free project builder for Windows

A personal project builder for Windows

Download for freeAll versions on GitHub

DoSka is a personal project builder for Windows. It is a simple yet powerful visual planning app that helps you structure any task, from a business process to a study project.

The app runs entirely locally, with no internet connection or cloud services, so all your data stays on your computer.

Use it to collect user stories, visualize processes and process charts, and break down tasks of any complexity.

Features

  • Hierarchical task lists (WBS)
  • User story collection
  • Links between notes
  • Checklists
  • Time tracking

Benefits

  • Fully offline (no internet or cloud)
  • Instant installation from a single file
  • A visual builder for any project
  • All data under your full control
  • Free for personal use

FAQ

How does DoSka work?

It is a local project builder for Windows, modeled on a magnetic board with colored sticky notes. You can create several projects with boards, link notes to each other, and start timers to keep track of time.

How many projects can I create?

You can create up to 20 projects, with up to 20 boards in each project and up to 100 notes on each board.

Can I export a project?

Project export is currently in development. This ensures that nobody can change your data without your knowledge.

Why does Windows show a warning during installation?

Official approval from Microsoft is pending, but the process is delayed by sanctions restrictions. This does not affect security: the app does not collect data and is completely safe.
