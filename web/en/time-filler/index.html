Time Filler — free shift and vacation scheduler for Windows

A local scheduler for small teams

Download for freeAll versions on GitHub

TimeFiller is a local scheduler for Windows, built for small teams. The app works completely offline, with no internet connection or cloud services, so all your data stays on your computer.

Use it to manage employee vacations, book clients, plan meetings and recurring events, and organize work in sprints.

Features

  • Shift schedules (2-on-2-off, 5/2)
  • Employee vacation management
  • Client bookings and meetings
  • Sprint support
  • Filtering by category

Benefits

  • Fully offline (no internet or cloud)
  • Instant installation from a single file
  • A visual calendar for every scenario
  • Adjustable interface transparency
  • Free for small teams

FAQ

How does TimeFiller work?

It is a local scheduler for Windows. You create date ranges with categories, and they appear in the calendar.

Can I create 2-on-2-off schedules?

Yes, the app lets you set up shifts quickly by repeating date ranges. You can create any work schedule.

How do I keep track of vacations?

Create a date range with a "Vacation" category for the employee. All vacations appear in the calendar and can be filtered.

Does it integrate with other software?

No, TimeFiller is a fully standalone app. It needs no integrations and works locally.
